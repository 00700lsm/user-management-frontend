# Shared UI

공통 Layout / Button / Input / Table / Pagination / Modal / StatusBadge / FormField를 재사용합니다.

기능 화면은 공통 UI 컴포넌트를 조합하며, 공통 컴포넌트 변경은 관련 담당자 리뷰가 필요합니다.

## 디자인 정본 적용

공통 UI의 실제 **모양·크기·색상 토큰·반응형·상태별 스타일**은 Frontend 루트의 [design.md](../../../design.md)를 반드시 참고합니다. 공통 컴포넌트 개발·변경 시 새 임의 스타일 대신 Token과 디자인 가이드를 먼저 적용하고, 화면별 중복 구현을 피합니다. Contract 공통 UI/IA 원칙이 상위 기준입니다.
